# Support

## How to get help

Cullr is an open-source project maintained on a best-effort basis.

- **Questions about using or developing Cullr:** search the
  [existing issues](https://github.com/QuinntyneBrown/cullr/issues) first,
  then open a new issue with the **Question** template.
- **Bugs:** open an issue with the **Bug report** template.
- **Ideas and feature requests:** open an issue with the **Feature request**
  template.
- **Security vulnerabilities:** do not open an issue. Follow
  [SECURITY.md](SECURITY.md).

Before asking, the answer may already be in:

- [README.md](README.md) for an overview and how to browse the mocks
- [AGENTS.md](AGENTS.md) for domain rules, architecture and conventions

## Response times

The maintainer responds on a best-effort basis. There is no paid support.
