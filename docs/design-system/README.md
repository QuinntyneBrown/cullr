# Cullr design system

A design system extracted from the HTML mocks in [`docs/mocks`](../mocks/README.md). Open [`index.html`](index.html) in a browser.

## Files

| Path | Purpose |
|---|---|
| `tokens/tokens.css` | Source of truth: palette, semantic tokens, light and dark themes. |
| `tokens/tokens.json` | DTCG export, generated by `tokens_to_json.py`; do not edit. |
| `tokens/contrast-pairs.json` | Every foreground and background pairing, checked for both themes. |
| `assets/components.css` | Product stylesheet: components, token-driven, with `data-state` hooks. |
| `assets/ds.css`, `assets/ds.js` | Documentation chrome: theme toggle, live token values and contrast. |

## Drift log

| Mock | Issue | Resolution |
|---|---|---|
| Ideas, Today | `btn--link` used without `btn` | Documented as a don't; mocks use `btn btn--link`. |
| Delete idea dialog | Two primary buttons | One primary, one danger. |
| Loading mocks | No `h1` | Visually hidden `h1` added. |
| Account page | Nav missing `aria-current`; avatar link unnamed | `aria-current="page"` and `aria-label` added. |
| Account and capture forms | Error text not linked to inputs | `aria-describedby` and `aria-invalid` documented. |
| Cards, margins | Off-grid padding (13, 18, 22px) | Snapped to the 4px scale. |
| Radii | Mixed values | Four steps: 6, 10, 16 and 20px. |
