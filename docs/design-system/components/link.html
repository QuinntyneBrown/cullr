Link

Navigates. Underlined, in the link colour, and always with a meaningful name.

Overview

Links take the reader somewhere: another page, a section, a file. They look like links: underlined text in --color-fg-link. If the action changes data, use a button.

Anatomy

  1. TextDescribes the destination; it is the accessible name.
  2. UnderlineAlways on, so colour is not the only cue.

Variants

Inline linkLink to a file (PDF)External
Standard, file and external links. External links announce that in the text.

Sizes

Links inherit the font size of the text they sit in.

Responsive behaviour

  • Links in running text wrap normally.
  • Standalone links in lists get 44px high tap areas with padding.

Theming

The component reads only semantic tokens, so both themes work with no component CSS. Compare:

Accessibility

Role and pattern

Native <a href>. Never a div or a link without href.

Keyboard

Keyboard
KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterFollows the link.

Focus

Same ring as buttons.

Labelling

Text makes sense out of context: Read the help guide, not click here. aria-current="page" marks the current page in navigation.

Contrast

Link on surface
Focus ring on surface

Motion

No motion beyond the shared hover and focus transitions, which use --duration-fast and are removed under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px where the control stands alone; neighbouring targets are 8px apart.

Content

  • Describe the destination.
  • Mention the type for files: Export guide (PDF).
  • Never click here or a bare URL.
