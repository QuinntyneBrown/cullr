Overview

Tabs filter one list into parts (all, logged, critiquing). They are not navigation between pages; for that use the sidebar.

Anatomy

  1. Tab listrole="tablist", scrolls sideways on phones.
  2. Tab40px tall; selected has an accent underline.
  3. Count badge (optional)Total items.

Variants

Tabs with count.
HTML
<div class="tabs" role="tablist" aria-label="Idea status"><button class="tab" role="tab" aria-selected="true" type="button">All <span class="badge">214</span></button><button class="tab" role="tab" aria-selected="false" type="button" tabindex="-1">Logged</button><button class="tab" role="tab" aria-selected="false" type="button" tabindex="-1">Critiquing</button></div>

Accessibility

Role and pattern

WAI-ARIA tabs: tablist, tab, tabpanel; roving tabindex.

Keyboard

Keyboard
KeyAction
TabMoves into the selected tab, then to the panel.
← / →Moves between tabs.
Home / EndFirst / last tab.
Enter, SpaceActivates when selection does not follow focus.

Focus

Ring on the focused tab; only the selected tab is in the tab order.

Labelling

List has aria-label; tabs aria-controls their panels.

Contrast

Selected text
Underline

Motion

No motion beyond the shared hover and focus transitions, which use --duration-fast and are removed under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px where the control stands alone; neighbouring targets are 8px apart.

Content

  • One or two words.
  • Counts after the label.
