Component

Button

Triggers an action. Five variants, three sizes, and one primary per view.

Overview

Use a button for something that does something: save, archive, curate. Use a link to go somewhere. Each view has one primary button; everything else is secondary, ghost or link.

Anatomy

  1. Leading icon (optional)20px, aria-hidden, inherits the label colour.
  2. LabelVerb phrase in sentence case; it is the accessible name.
  3. ContainerHeight from --control-height-*, --radius-md, 1px border.

Variants

Emphasis from highest to lowest. Danger is only for destructive confirmations.
HTML
<button class="btn btn--primary" type="button" >Primary</button><button class="btn " type="button" >Secondary</button><button class="btn btn--ghost" type="button" >Ghost</button><button class="btn btn--link" type="button" >Link</button><button class="btn btn--danger" type="button" >Danger</button>
Icon-only buttons need aria-label. Note: btn--link always accompanies btn.
HTML
<button class="btn btn--icon" type="button" aria-label="Edit idea"><svg class="icon" aria-hidden="true" viewBox="0 0 24 24"><path d="M4 20h4L19.5 8.5a2.1 2.1 0 0 0-3-3L5 17v3z"/></svg></button><button class="btn btn--block" type="button" >Block</button>

Sizes

Heights come from --control-height-sm/md/lg.
HTML
<button class="btn btn--primary btn--sm" type="button" >Small · 32px</button><button class="btn btn--primary" type="button" >Medium · 40px</button><button class="btn btn--primary btn--lg" type="button" >Large · 48px</button>

States

Hover, focus and active are forced with data-state for review; real pages use :hover, :focus-visible and :active.

Responsive behaviour

  • Below 768px the primary button in a form becomes full width with .btn--block; secondary actions stack beneath it.
  • In dialog footers, buttons wrap and the primary stays last in reading order.
  • Labels never truncate; shorten the verb phrase instead.

Accessibility

Role and pattern

Native <button type="button"> (or type="submit" in a form). A link styled as a button is still an <a href>.

Keyboard

Keyboard
KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter, SpaceActivates the button.

Focus

2px ring with a 2px offset on :focus-visible; it contrasts 3:1 with both the button and the page.

Labelling

The visible label is the accessible name. Icon-only buttons set aria-label. Loading sets aria-busy="true" and keeps its name.

Contrast

Label on primary
Label on danger
Secondary border

Motion

Background transitions over --duration-fast; the active state moves 1px. Both are removed under reduced motion; the loading spinner keeps turning.

Touch

Medium and large exceed 44px tall. Small (32px) is only used in rows that are also tappable.

Content

  • Verb phrases: Save changes, Archive idea, never OK or Submit.
  • Destructive labels name the loss: Delete idea.
  • Three words or fewer where possible.
