Overview

Use a table when users compare ideas across several attributes. For a simple list of one-line items use list.

Anatomy

  1. CaptionVisually hidden name for the table.
  2. Header cellsscope="col".
  3. RowsHover highlight; selected rows tinted.
  4. Wrapper.table-wrap scrolls sideways on phones.

Responsive behaviour

  • The wrapper scrolls inside itself at 360px; the first column stays readable.
  • Row actions are always visible on touch (hover: none).

Accessibility

Role and pattern

Native table; sortable headers contain buttons with aria-sort on the th.

Keyboard

Keyboard
KeyAction
Tab / Shift+TabMoves focus to and from interactive content in DOM order.
Enter / SpaceSorts when on a header button.

Focus

Ring on buttons and links in cells; the wrapper is focusable (tabindex="0") when it scrolls.

Labelling

Caption names the table; action columns have a visually hidden header.

Contrast

Cell text
Header text

Motion

No motion beyond the shared hover and focus transitions, which use --duration-fast and are removed under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px where the control stands alone; neighbouring targets are 8px apart.

Content

  • Header nouns.
  • Dates as Tue 14 Oct.
