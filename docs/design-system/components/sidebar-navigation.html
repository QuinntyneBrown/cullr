Overview

Five destinations: Today, Ideas, Curated, Archive, Settings. The current page is marked with aria-current="page" and a fill.

Anatomy

  1. LinkIcon + label, 44px tall.
  2. CurrentAccent fill and aria-current.

Responsive behaviour

  • Below 1024px it is hidden and opens from the top bar menu button as a panel (data-open="true").
  • From 1024px it is sticky and full height.

Accessibility

Role and pattern

<nav aria-label="Primary"> with links; current via aria-current.

Keyboard

Keyboard
KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterFollows the link.

Focus

Ring inside the link; panel returns focus to the menu button on close.

Labelling

Visible text; icons are decorative.

Contrast

Current link
Link text

Motion

No motion beyond the shared hover and focus transitions, which use --duration-fast and are removed under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px where the control stands alone; neighbouring targets are 8px apart.
