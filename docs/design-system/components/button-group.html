Button group

Joins related buttons into one control, such as a period switcher.

Overview

Group buttons that act on the same thing. A group of toggles uses aria-pressed; a plain group is a set of related actions. For a single choice that changes content, use tabs.

Anatomy

  1. Container.btn-group with role="group" and an aria-label.
  2. ButtonsShared borders; corners rounded only at the ends.

Variants

Segmented toggle group.
HTML
<div class="btn-group" role="group" aria-label="Filter"><button class="btn " type="button" aria-pressed="true">Today</button><button class="btn " type="button" aria-pressed="false">Week</button><button class="btn " type="button" aria-pressed="false">Month</button></div>

Sizes

Buttons inside inherit the button sizes; the group has no size of its own.

States

State matrix
VariantDefaultHoverFocusSelected
Toggle

Responsive behaviour

  • At 360px a group of up to four short labels fits on one row.
  • Longer groups wrap into stacked buttons; prefer a select beyond five options.

Accessibility

Role and pattern

A role="group" with an accessible name containing toggle buttons (aria-pressed).

Keyboard

Keyboard
KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
Enter, SpaceToggles the focused button.

Focus

Each button shows its own ring; the focused button is raised above neighbours.

Labelling

The group has aria-label; each button has a visible label. Pressed state is conveyed by aria-pressed and by fill, not colour alone.

Contrast

Focus ring on surface

Motion

No motion beyond the shared hover and focus transitions, which use --duration-fast and are removed under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px where the control stands alone; neighbouring targets are 8px apart.

Content

  • Short nouns: Today, Week, Month.
  • Parallel wording across the group.
