Textarea

Overview

Use for the idea description, critique notes and reasons. It grows vertically; set rows to the expected length.

Anatomy

  1. LabelVisible above.
  2. TextareaMin height of three rows; resizes vertically.
  3. CounterCurrent and limit; announced politely near the limit.

Variants

With counter.
HTML
<label class="field"><span class="field__label">Idea</span><textarea class="textarea" rows="3" >A free notice board for your street.</textarea><span class="field__counter">38 / 500</span></label>

Sizes

Height is set by <code>rows</code>; width follows the column.

States

State matrix
VariantDefaultHoverFocusDisabledInvalid
Textarea

Responsive behaviour

  • Full width of its column at every size.
  • Vertical resize only, so it never breaks the layout.

Accessibility

Role and pattern

Native <textarea> in a label.

Keyboard

Keyboard
KeyAction
Tab / Shift+TabMoves focus to and from the control in DOM order.
EnterInserts a new line.

Focus

Same as text field.

Labelling

Visible label; counter exposed with aria-live="polite" only when within 10% of the limit; limits stated in help text.

Contrast

Border
Focus ring on surface

Motion

No motion beyond the shared hover and focus transitions, which use --duration-fast and are removed under prefers-reduced-motion.

Touch

Targets are at least 24px and 44px where the control stands alone; neighbouring targets are 8px apart.

Content

  • Say the limit in help text when there is one.
  • Placeholder shows an example, not instructions.
