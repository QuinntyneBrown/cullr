Overview

Full-page errors reuse the empty state with a danger icon. Each has one h1, a plain explanation and a way out.

Anatomy

  1. IconDanger tone, decorative.
  2. Headingh1 on full pages.
  3. ExplanationWhat happened.
  4. ActionsRetry and a route home.
