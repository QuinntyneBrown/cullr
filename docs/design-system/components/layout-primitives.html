Overview

Pages are arranged with four primitives rather than custom CSS: .container (centred, margin from --layout-margin), .stack (vertical rhythm), .cluster (wrapping row) and .grid (responsive columns).

Anatomy

  1. StackChildren separated by --space-4.
  2. ClusterRow with wrap and gap --space-2.
  3. Grid1, 2 then 3 columns.
  4. ContainerMax width with page margin.

Sizes

States

Static layout.

Responsive behaviour

  • Grid: 1 column, 2 from 768px, 3 from 1024px.
  • Container margin grows with the layout margin token.
