Theming

Light is the default; dark follows the system preference and can be forced with data-theme. Components never know which theme is active.

Overview

Themes live entirely in tokens/tokens.css. The light theme is set on :root; the dark theme is set on [data-theme="dark"] and, for visitors who have not chosen, inside @media (prefers-color-scheme: dark) on :root:not([data-theme]).

Adding a theme

  1. Copy the dark block in tokens.css and change the selector to [data-theme="name"].
  2. Change only --color-* and shadow values.
  3. Run check_contrast.py; every pair must pass in the new theme.
  4. Run tokens_to_json.py to refresh tokens.json.

tokens.json

tokens/tokens.json is a DTCG export of every token, with a mode for each theme. Generate it; never edit it by hand.
