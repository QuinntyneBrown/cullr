Foundation

Elevation

Three shadow levels and a named z-index order. In dark theme surfaces get lighter as they rise, because shadows barely show.

WCAG 2.2 AAStatus: stableExtracted 2026-10-14
  • Overview
  • Shadow levels
  • Surface hierarchy
  • Z-order
  • Tokens

Overview

Use the lowest level that separates the layer from what is beneath it. Cards sit flat with a border; menus and popovers use level 2; dialogs use level 3.

Z-order

Never use a literal z-index. The order from back to front is sticky, dropdown, popover, overlay, modal, toast, tooltip.
