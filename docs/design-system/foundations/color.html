Color

Cullr uses one blue accent on a calm neutral ramp, with green, amber and red kept for status. Every semantic colour has a light and a dark value and every text pairing is checked.

Overview

Colour is defined in two tiers. Palette tokens (--palette-*) are raw ramps and are never used by components. Semantic tokens (--color-*) say what a colour is for and switch between themes. Components read only the semantic tier.

Colour is never the only signal: errors carry an icon and text, selected items carry a check or a weight change, and status badges carry a label.

Usage rules

  • Use --color-accent for the one primary action per view and for selected state; do not use it for decoration.
  • Status colours carry meaning only: info, success, warning, danger. Do not use red for anything that is not a problem or a destructive action.
  • Never put --color-fg-subtle text on a tinted background; it is only checked against surface and page.
  • Add a colour by adding a semantic token with both theme values and a pair in contrast-pairs.json.
