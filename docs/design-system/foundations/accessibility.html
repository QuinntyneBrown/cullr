Foundation

Accessibility

Cullr targets WCAG 2.2 AA. These commitments are kept by every component and checked on every page.

WCAG 2.2 AAStatus: stableExtracted 2026-10-14
  • Overview

  • Focus ring

Overview

The checks below are part of the definition of done for any screen. Each component page repeats the ones that apply to it.

Commitments

  • Contrast: 4.5:1 for text, 3:1 for large text, borders and focus rings; checked in both themes.
  • Focus: a 2px ring with a 2px offset on every interactive element; never removed, never hidden behind sticky bars (2.4.11).
  • Keyboard: everything works without a pointer; there is a skip link and a logical tab order. Dialogs trap focus and return it.
  • Names: every control has a visible label; icon-only buttons have aria-label.
  • Targets: at least 24px, and 44px where the target stands alone (2.5.8).
  • Status: toasts and inline results use role="status"; errors use role="alert" (4.1.3).
  • Motion: reduced motion is honoured; nothing flashes.
  • Reflow: no horizontal scroll at 320px; text spacing can be changed without loss.
  • Forms: errors name the field and the fix, are linked with aria-describedby and summarised at the top; no redundant entry (3.3.7).
  • Headings: one <h1> per page, in order, including loading and error states.
