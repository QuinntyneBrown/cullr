Foundation

Motion

Short, functional motion: 120ms for hover, 200ms for reveals, 320ms for large moves. Everything is removed when the user asks for reduced motion.

WCAG 2.2 AAStatus: stableExtracted 2026-10-14
  • Overview
  • Replayable demos
  • Reduced motion
  • Tokens

Overview

Motion explains what changed (a toast arriving, a menu opening) and never decorates. Enter with --ease-enter, leave with --ease-exit, and use --ease-standard for everything else. Under prefers-reduced-motion: reduce the duration tokens become 0.01ms, so every transition collapses without any component code.

Replayable demos

Reduced motion

Toggle Reduce motion in your operating system to see the difference. Spinners keep rotating because they are status indicators; skeleton shimmer stops.
