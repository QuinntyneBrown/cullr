Foundation

Shape

Four corner radii and two border widths. Controls are 10px, cards 16px, dialogs 20px.

WCAG 2.2 AAStatus: stableExtracted 2026-10-14

Overview

Shape stays friendly but quiet. Controls (buttons, inputs) use --radius-md, small elements (tooltips, chips inside rows) use --radius-sm, cards use --radius-lg, dialog panels use --radius-xl, and pills and avatars use --radius-full.
