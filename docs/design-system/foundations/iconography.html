Foundation

Iconography

Inline SVG on a 24-unit grid, 2px stroke, round caps, using currentColor. Icons are always decorative or named by a button.

WCAG 2.2 AAStatus: stableExtracted 2026-10-14
  • Overview
  • Icons in use
  • Rules

Overview

Icons are inlined, not font-based, so they inherit text colour and need no network request. Sizes: .icon--sm 16px, default 20px, .icon--lg 24px.

Rules

  • Every icon is aria-hidden="true"; the button or link next to it supplies the name.
  • An icon-only button needs aria-label and a tooltip.
  • Pair status icons with text: alert, toast, inline message.
  • Stroke only, no fills, stroke="currentColor" comes from .icon.
