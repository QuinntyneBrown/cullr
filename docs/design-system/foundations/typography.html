Foundation

Typography

One sans family for everything and a mono family for code and keys. A modular scale, five roles of weight and a 65-character measure.

Overview

Cullr is a reading app first: the owner skims many short ideas a day. Type is therefore plain, generous and consistent. Body text is 16px and never smaller than 14px, line height is 1.5, and prose is capped at --layout-measure (65ch).

Measure and rhythm

Porch Light is a free notice board for a single street. Neighbours post lost cats, spare ladders and block-party plans. The line you are reading is capped at 65 characters so the eye never has to travel far to find the next line.

  • Prose max width is --layout-measure; forms and cards are narrower still.
  • Headings use --line-height-tight; body uses --line-height-normal.
  • Do not justify text. Do not letter-space body text. Do not use all caps except the .overline label.
