How to use this system

  • Link tokens/tokens.css, then assets/components.css in any page. Components read only semantic tokens.
  • Toggle the theme with the button in the sidebar; every live value and contrast ratio updates.
  • Copy class names from each component’s Code section; copy values from tokens/tokens.json.
  • Add a token or component by updating the stylesheet, the page, and contrast-pairs.json together, then run the two checkers.
