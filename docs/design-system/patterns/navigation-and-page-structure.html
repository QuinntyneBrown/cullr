Navigation and page structure

A predictable shell: skip link, top bar, sidebar, page header, content, footer.

Overview

Every signed-in page uses the same shell, so the owner always knows where they are.

Built from: top bar, sidebar navigation, breadcrumb, skip link.

When to use

  • All signed-in pages.

Structure and live example

skip link
topbar (sticky)
sidebar (from 1024px) | main#main
                      page-header: breadcrumb? h1 actions
                      content
footer

States

The current page is marked in the sidebar with aria-current. A page header holds one h1 and the primary action.

Responsive behaviour

  • Sidebar becomes a panel below 1024px.
  • Page header actions wrap under the title.

Accessibility

  • Landmarks: header, nav, main, footer.
  • One h1.
  • Skip link first.

Content

  • One-word nav labels.
