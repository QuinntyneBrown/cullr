Pattern

Forms

One column, visible labels, errors that say how to fix.

Overview

Every form in Cullr is capture, edit or settings. The pattern keeps them quick to fill and easy to fix.

Built from: form layout, form field, text field, button.

When to use

  • Capturing or editing an idea.
  • Account and settings.
  • Sign-in and password reset.

Structure and live example

Single column; primary last.
HTML
<form class="stack" style="max-width:24rem;"><label class="field"><span class="field__label">Title</span><input class="input" type="text" ></label><label class="field"><span class="field__label">Category</span><input class="input" type="text" ></label><div class="form-actions"><button class="btn " type="button" >Cancel</button><button class="btn btn--primary" type="submit">Save changes</button></div></form>

States

Fix 2 problems
  • Title: enter at least 3 characters
Invalid: summary plus inline errors.
HTML
<div class="form-summary" role="alert"><b>Fix 2 problems</b><ul><li><a href="#top">Title: enter at least 3 characters</a></li></ul></div><label class="field"><span class="field__label">Title</span><input class="input" type="text" aria-invalid="true"><span class="field__error">Enter at least 3 characters.</span></label>
Submitting: the pressed button shows busy.
HTML
<button class="btn btn--primary" type="submit" aria-busy="true">Save changes</button>

Responsive behaviour

  • Single column at all sizes; max width 32rem.
  • Actions stack with the primary first in reading order on phones.

Accessibility

  • Validate on submit, then live on the fields that failed.
  • Focus the error summary on a failed submit.
  • Every control has a visible label and autocomplete where it applies.
  • Do not require re-entry of known data (3.3.7).

Content

  • Primary label names the action.
  • Errors: what is wrong + fix.
