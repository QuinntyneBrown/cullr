Feedback and loading

Match the feedback to the moment: inline, toast, alert, skeleton or spinner.

Overview

Pick the lightest feedback that still tells the user what happened.

Built from: toast, alert, skeleton, spinner, progress bar, inline message.

When to use

  • Saving a change, finishing an action, a failed request, a first page load.

Responsive behaviour

  • Toasts go bottom full-width on phones.
  • Skeletons match final heights.

Accessibility

  • Status updates use live regions.
  • Busy buttons keep their name.
  • Never rely on colour alone.

Content

  • Past tense for done: Idea archived.
  • Progressive tense for doing: Saving….
